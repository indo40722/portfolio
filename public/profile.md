## 代表制作

### VCL / Virtual Chemistry Lab

- Detail: https://indo40722.github.io/portfolio/#/works/vcl
- 概要: Joy-Con操作と3D表現を組み合わせ、化学実験を安全に体験できる学習システム。
- 担当: 4人チームのリーダー兼フロントエンド・画面体験担当。
- 担当内容: 企画整理、入力方式の検証、技術選定、役割分担、ドキュメント整理、Joy-Con入力と画面連携。
- 成果: HAL EVENT WEEKで金賞。VCLの初期プロトタイプでも銅賞。
- 技術: Node.js, Socket.IO, Three.js, Joy-Con.

### Hoppy

- Detail: https://indo40722.github.io/portfolio/#/works/hoppy
- 概要: カメラ、アウトドア用品、楽器などを貸し借りできるWebサービス。
- 担当: コミュニティ機能とサポート機能。
- 担当内容: 投稿、画像投稿、いいね、コメント、Q&A、フォロー、お問い合わせ、FAQ、利用ガイド。
- 成果: Webシステム学内コンペで銀賞。4人チームで7か月制作し、チーム合計開発時間は1044時間。
- 技術: Python, Flask, HTML, CSS, JavaScript, Database Design.

### Tea Bridge / T3

- Detail: https://indo40722.github.io/portfolio/#/works/t3-tea-bridge
- 概要: 日本茶農家と海外のカフェ・食品ブランドをつなぐ、抹茶の仕入れ相談所として制作したWebプロトタイプ。
- 参加経緯: 1日目の個人発表後、テーマ内で採択されたTea Bridge案へ合流。
- 担当: リサーチ、営業候補整理、Webプロトタイプ制作。
- 担当内容: 中間業者や輸出手続き、競合サービスの調査、Google Places APIを使った候補抽出の検証、公開情報での確認を前提にした営業候補リサーチ、Codexを使ったUI実装補助、商品一覧・詳細、理念ページ、農園ツアー、問い合わせ、商談台帳型の運用画面制作。
- 成果: テラッカソン10th / kakeruXテーマで個人賞・チーム賞。個人賞では、自分の個人案ではないプロジェクトにも当事者意識を持って取り組んだ姿勢を評価された。
- 技術: Next.js, React, TypeScript, Tailwind CSS, Google Places API, Codex.

### 学生データ分析AWARD 2025

- Detail: https://indo40722.github.io/portfolio/#/works/data-award
- 概要: 初対面の3人チームで豊島区の2040年問題に取り組んだ、1泊2日の合宿型コンテスト。
- テーマ: 豊島区の2040年問題。
- 担当: ChatGPT、Claude Code、NotebookLMなどを使った資料理解、オープンデータの読み込み、論点整理、発表ストーリーの組み立て。
- 判断: 生成AIで資料理解と仮説出しの初速を上げつつ、数字の根拠や提案として通る筋はチームで確認した。
- 提案: 防災リスクの可視化、地域コミュニティ形成、防災情報のオンボーディングなどを軸にした。
- 成果: 準優勝。
- 公開記事: https://techplay.jp/column/2101
